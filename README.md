# 🌟 AI Cloud Azure Developer (Zero-to-Hero Labs)

Welcome to the **AI Cloud Azure Developer** hands-on curriculum and lab repository! 🚀

This repository contains step-by-step, beginner-friendly learning paths, Infrastructure-as-Code (Bicep/PowerShell) templates, interactive reflection prompts, and knowledge checks designed to guide learners from ground zero to certified **Azure AI Engineer Associate (AI-102)** and **Azure AI Fundamentals (AI-900)**.

---

## 🗺️ Repository Structure

*   📁 [**`ai-labs/`**](ai-labs/) — Master learning roadmaps and structured AI modules.
    *   📖 [**`roadmap-mina.md`**](ai-labs/roadmap-mina.md) — The visual zero-to-hero learning path and progress tracker.
*   📁 [**`ai-labs-mina/`**](ai-labs-mina/) — Hands-on practical lab modules:
    *   📍 [**`lab-000-portal-cost-safety/`**](ai-labs-mina/lab-000-portal-cost-safety/) — Azure Portal Safari & Cost Management Safety Net.
    *   📍 [**`lab-001-resource-groups/`**](ai-labs-mina/lab-001-resource-groups/) — Resource Groups, Tagging & Cloud Organization.
*   📁 [**`.ai/`**](.ai/) — Custom AI personas, workflows, and cloud mentor role definitions (*"Jojo"*).

---

## 🛠️ Getting Started

1. Clone this repository:
   ```bash
   git clone git@github.com:mina-mtb/AZ200.git
   # or via HTTPS:
   git clone https://github.com/mina-mtb/AZ200.git
   ```
2. Check your progress in [**`ai-labs/roadmap-mina.md`**](ai-labs/roadmap-mina.md).
3. Start with **Lab 000** or **Lab 001** and follow the step-by-step guides in each lab's `README.md`.
